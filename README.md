# Visualizations

Interactive visualizations of research data, published with GitHub Pages at
https://chcomin.github.io/visualizations/. Each visualization is a static page in its own folder:

- [`capillary-network-3d/`](capillary-network-3d/): 3D reconstruction of the cortical capillary network in confocal
  stacks (CD31).

To add a visualization, create a folder with its own `index.html` and data, and add a link to it in `index.html`.
