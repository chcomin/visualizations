# Cortical capillary network, interactive 3D viewer

Static page; it needs a web server (GitHub Pages, or `python -m http.server` in the repository root, then
http://localhost:8000/capillary-network-3d/). It does not work when opened as a local file, because the browser blocks
loading the data files. three.js 0.160.0 is loaded from cdn.jsdelivr.net.

A sample can be opened directly with `?sample=<id>`, e.g. `?sample=2026-10-19-wt-cd31-120-488-larger-left-01`; the
address bar always shows the link to the current sample.

## Files

- `samples.json`: the list of samples (id, genotype, date, name as in the original data) and the default sample.
- `data/<id>/vessels.bin.gz`: centerlines and radii, gzip-compressed int16 arrays z, y, x (units of 0.05 µm) and
  r (units of 0.02 µm), each with the samples of all vessel segments and then the spheres at the nodes. Within a
  segment, every sample after the first is the difference from the previous one.
- `data/<id>/meta.json`: number of samples of each segment, number of spheres, field size and network statistics.
- `data/<id>/mip.jpg`: maximum projection of the raw stack (1024 × 1024), shown under the vessels.

The data are generated by `code/vessel_viewer_data.py` of the analysis (steps `geometry` and `site`).

## What the page draws

- **Tubes:** smoothed centerlines of the main graph (guided pruning); the radius is the vessel radius in the imaging
  plane, from the distance transform of the mask.
- **Joints:** near junctions the radius is clamped, so that junctions do not bulge. A sphere slightly thinner than
  the thinnest vessel fills each joint.
- **Tips:** closed with a flat disk.
- **Hidden stubs:** dead ends shorter than the parent vessel's radius plus their own radius are not drawn. They end
  inside the parent vessel.
- **Depth:** the depth axis is nominal; it is not corrected for refractive index.

Behavior: the view rotates slowly by itself. It stops while the user drags (rotate or pan), and resumes 3 s after
the mouse or finger is released; zooming with the wheel does not stop it. The settings and the sample selector are
behind the menu button (top left); the color legend stays in the bottom left corner. When the new sample has the same
field size, the view is kept, which makes comparing samples easier.
